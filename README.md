# Pickleball Gyan

India-first independent pickleball publication.

## Canonical domain
https://pickleballgyan.in/

`pickleballgyan.com` should redirect permanently to the matching `.in` URL and should not host a duplicate site.

## Stack
Static HTML/CSS/JS, designed for GitHub Pages.

## Launch information architecture
- Play
- Gear
- Scene
- Data
- Places
- About / Editorial / Methodology / Corrections

## Deployment
1. Create a public GitHub repository named `pickleballgyan`.
2. Upload the contents of this folder to the repository root.
3. Enable GitHub Pages from the `main` branch, root folder.
4. Set the custom domain to `pickleballgyan.in`.
5. Configure Namecheap DNS using the current GitHub Pages custom-domain instructions.
6. Redirect `pickleballgyan.com` and `www.pickleballgyan.com` permanently to `https://pickleballgyan.in/`.

Do not publish unverified statistics, prices or venue records simply to populate launch pages.
