# Gear market data standard

This directory tracks the Indian market evidence behind Pickleball Gyan gear coverage. A product record is not a review and does not imply hands-on testing.

Every price record must state the seller, product identity, listed rupee price, tax or delivery caveat where visible, availability status, source URL and date checked. Manufacturer claims must be stored as claims. Performance conclusions require documented testing or independent evidence.

## Publication labels

- verified_listing: a current direct seller or manufacturer listing was checked.
- reported_listing: an identifiable secondary listing was found but not confirmed.
- unavailable: source page did not show current purchasable stock.
- discontinued_or_unknown: product status cannot be established.
