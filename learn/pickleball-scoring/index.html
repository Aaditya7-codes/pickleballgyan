Pickleball scoring, explained

In standard doubles side-out scoring, call three numbers: the serving team’s score, the receiving team’s score, then server one or two. A new game begins 0-0-2.

Updated 16 August 2026Standard side-out modelCheck event rules

The shortcut

Only servers score.

Win a rally while receiving: you gain the serve, not a point. In doubles, both partners normally get a service turn before a side out.

Important caveat

This guide explains the traditional side-out format. An organiser can publish a different format, including rally scoring or a different game length. For a tournament, its current regulations control.

Why doubles starts at 0-0-2

The opening serving team receives only one service turn. Calling 0-0-2 signals that the starting server is treated as the second server for that opening turn. When that side loses a rally, it is immediately a side out rather than a second teammate service turn. This reduces the advantage of serving first.

How the three-number call works

At 4-2-1, the serving side has four points, the receiving side has two and the player serving is the first server for that service turn. At 4-2-2, the score has not changed, but the second server is now serving. Say the score before every serve; it is a practical check on position as well as score.

What happens after each rally

  1. Serving side wins: it scores one point. The server and partner swap left/right positions; the same player serves again.
  2. Serving side loses, first server: no point is scored. The partner serves, and the third number changes from 1 to 2.
  3. Serving side loses, second server: no point is scored. It is a side out; the other team serves, beginning with the player correctly positioned on the right/even side.

A short doubles example

0-0-2: Team A starts. A loses the rally. It is a side out; Team B serves.

0-0-1: Team B’s first server wins the rally. Team B scores, swaps sides and continues.

1-0-1: Team B’s first server loses the next rally. No point; the partner serves.

1-0-2: Team B’s second server loses the rally. Side out. Team A serves at 0-1-1.

The point is not to memorise a script. Keep these two ideas clear: only the server scores, and the third number tells you which service turn the team is using.

The even-score position check

In standard doubles, the player who first served for a team in that game should be on the right/even side when that team’s score is even, and on the left/odd side when it is odd. If that relationship breaks, either the score or the player positions need checking.

Singles scoring

Singles uses the same basic principle: only the serving player scores under standard side-out scoring. Call two numbers, server score then receiver score. There is no third server number because each side has one player. When a server loses a rally, it is a side out.

Rally scoring and tournament formats

In rally scoring, every rally produces a point, whether the serving or receiving side wins it. This can be used in some local, league or event formats. Do not assume it applies simply because someone calls a game “competitive.” Before an event, confirm the game target, win-by margin, scoring system and the exact rules in force.

Common scoring mistakes

  • Giving a point to the receiving side after it wins a rally in side-out scoring.
  • Thinking “server two” permanently belongs to one player. It is a service-turn label, not a player identity.
  • Forgetting that the opening turn is 0-0-2.
  • Switching sides after every rally instead of only after the serving side scores.
  • Applying a rally-scoring format to a standard side-out game without agreement.
